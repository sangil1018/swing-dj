# 🎷 SwingDJ

**스윙 재즈 댄스를 위한 하이파이 DJ 웹 플레이어**

🔗 **바로 실행하기 (GitHub Pages)**: **[https://sangil1018.github.io/swing-dj/](https://sangil1018.github.io/swing-dj/)**

SwingDJ는 스윙 댄스 소셜 파티, 연습실, 대회(컴핏) 현장에서 음악을 플레이하는 DJ들을 위해 만들어진 웹 기반의 오디오 플레이어입니다. 별도의 설치 없이 브라우저(또는 PWA 앱 설치)만으로 **메인 스피커와 DJ 모니터링 헤드폰(CUE) 분리 출력**, **7단계 BPM 속도별 색상 필터**, **컴핏모드 타이머**, **내장 메트로놈**, **다중 플레이리스트 탭 & 보관함**, 그리고 **Pure Direct (Bit-Perfect) 하이파이 오디오 엔진**을 제공합니다.

> 🔒 **프라이버시 & 오프라인 안심 설계**: 웹 주소(`github.io`)로 접속하더라도 **사용자가 추가한 음원 파일은 외부 서버로 절대 전송되지 않으며**, 기기 브라우저 내부에서만 100% 로컬로 디코딩·분석·재생됩니다.

## ✨ 주요 기능

*   **🎧 분리 출력 (Main / CUE)**: 플로어로 나가는 메인 음악과 다음 곡을 미리 들어볼 수 있는 CUE 출력을 각각 다른 오디오 장치(USB 오디오 인터페이스, 내장 헤드폰 단자 등)로 할당할 수 있습니다.
*   **🌈 7단계 BPM 속도별 색상 구분 & 원클릭 필터**:
    *   `~160` · `160~180` · `180~200` · `200~230` · `230~260` · `260~300` · `300~` 7개 템포 구간별로 고유 색상이 자동 부여되며, 상단 색상 칩을 클릭해 해당 속도 대역의 곡만 즉시 필터링할 수 있습니다.
*   **🎛️ 하이브리드 데크 전환기 (세그먼트 탭 + 안전 좌우 스와이프 + `⊞` 전체 펼침)**:
    *   중앙 상단 탭 바(`▶️ 플레이 컨트롤` / `🏆 컴핏모드` / `⏱️ 메트로놈`)를 원탭 클릭하거나, 카드 배경을 좌우로 스와이프(슬라이더·시크 바 간섭 자동 차단)하여 빠르게 화면을 전환할 수 있습니다.
    *   각 탭 우측에 실시간 상태 배지(`재생중`, `01:40`, `▶ 184`)가 상시 표시되며, 대화면 모니터에서는 우측 `⊞` 버튼으로 3개 카드를 한 번에 펼쳐 볼 수도 있습니다.
*   **🏆 컴핏모드 (대회용 타이머 & 자동 페이드아웃)**:
    *   기본 **1분 40초(`01:40`)** 카운트다운 및 **마지막 5초 자동 S-Curve 페이드아웃 후 정지** 기능을 지원합니다.
    *   프리셋(`1:00`, `1:30`, `1:40`, `2:00`), 미세 조절(`-10s`, `-5s`, `+5s`, `+10s`), 직접 시간/페이드 초 입력이 가능하며 진행 바 클릭으로 원하는 시점 테스트도 가능합니다. (단축키 `C`)
*   **⏱️ 내장 메트로놈 (Lookahead 정밀 스케줄러)**:
    *   Web Audio 하드웨어 클럭 기반으로 흔들림 없는 클릭 사운드와 4비트 시각 LED를 제공합니다.
    *   출력을 **🎧 CUE (헤드폰 전용)** 또는 **🔊 MAIN (스피커)**으로 전환할 수 있으며, `🎵 현재곡` BPM 동기화, `🥁 TAP` 템포, 정박(1-4) / 스윙 강세(2 & 4) / 백비트 모드를 지원합니다. (단축키 `M`)
*   **📂 멀티 플레이리스트 탭 & 보관함 (`💾 보관함`)**:
    *   여러 개의 플레이리스트 탭(`1부 소셜`, `2부 고속`, `컴핏 예선` 등)을 동시에 열어두고 전환할 수 있습니다.
    *   브라우저 내부 보관함(IndexedDB 파일 핸들 연동)에 세트를 저장·복원하거나, `.swingdj.json` 및 `.m3u8` 파일로 내보내기/가져오기를 지원합니다.
*   **📋 실전 중심의 큐(Queue) & CUE 미리듣기**:
    *   **바로 다음 곡 예약 (`+다음` / `N`)**: 현재 재생 중인 곡 바로 다음 순서에 즉시 끼워 넣습니다.
    *   **큐 예상 소요 시간 표시**: 대기 중인 곡 수와 총 재생 예정 시간을 실시간 합산하여 타임슬롯 구성을 돕습니다.
    *   **CUE 구간 점프**: 헤드폰 미리듣기 중 시크 바 드래그 또는 `처음` · `중반` · `엔딩`(종료 15초 전) 버튼으로 인트로와 엔딩(페이드아웃/박수 유무)을 원클릭 점검합니다.
*   **🎚️ 하이파이 오디오 엔진 (Pure Direct & Auto-Gain & Mono)**:
    *   **진정한 Pure Direct (`Bit-Perfect`) 직결 경로**: 5밴드 EQ가 모두 `0 dB`이고 `Auto-Gain`이 꺼진 상태에서는 필터와 컴프레서를 신호 경로에서 완전히 분리(`Source → Gain → Destination`)하여 원음 그대로 출력합니다.
    *   **네이티브 샘플레이트 동기화**: OS 및 외장 DAC의 네이티브 샘플레이트(`44.1kHz`, `48kHz`, `96kHz` 등)에 자동 동기화되어 이중 리샘플링 열화를 방지합니다 (`#eq-sr-badge`에 `48kHz Pure` / `48kHz DSP` 표시).
    *   **트랙 라우드니스(`dBFS`) 측정 & `🔊 Auto-Gain`**: 곡 로드 시 무음을 제외한 Gated RMS 음량(`dBFS`)과 트루 피크를 자동 측정하며, `Auto-Gain` 활성화 시 트랙 간 음량을 `-14.0 dBFS` 기준으로 자동 평준화(피크 클리핑 방지 실링 포함)합니다.
    *   **클럽/빠 PA 모노 서밍 (`🎧 Mono`)**: 1950~60년대 극단적 좌/우 패닝(Hard-panned) 스테레오 재즈 음원을 빠/홀 PA 스피커에서 재생할 때 어느 위치에서나 모든 악기가 균등하게 들리도록 모노 합산 출력을 지원합니다.
    *   **Butterworth Q(`0.707`) 5밴드 EQ & 안티클릭 엔벨로프**: EQ 양(+) 부스트 시 프리앰프 헤드룸을 자동 보상하고 `-0.5 dBFS` 투명 브릭월 피크 리미터로 디지털 클리핑을 차단하며, 시크/정지 시 `7~8ms` 마이크로 페이드 엔벨로프로 팝 노이즈를 제거합니다.
*   **🎨 6종 컬러 테마**: 클래식 골드, 사보이 벨벳, 미드나잇 블루, 에메랄드 클럽, 사이버 네온, 로즈 라운지 테마를 실시간으로 전환하고 자동 저장합니다.

## 🚀 실행 방법 (MacBook / Android 태블릿 / Windows)

### 방법 1. GitHub Pages 웹 접속 & PWA 앱 설치 (추천 ⭐)
별도 파일 다운로드나 서버 실행 없이 아래 주소로 접속하면 모든 기기에서 즉시 실행됩니다.

👉 **[https://sangil1018.github.io/swing-dj/](https://sangil1018.github.io/swing-dj/)**

*   **안드로이드 태블릿 / 스마트폰**:
    1. **Chrome** 브라우저로 위 주소에 접속합니다.
    2. 우측 상단 메뉴(`⋮`) → **홈 화면에 추가 (또는 앱 설치)** 를 선택합니다.
    3. 홈 화면에 생성된 **🎷 SwingDJ** 아이콘을 실행하면 주소창 없는 전체화면 앱으로 동작하며, 서비스 워커(`sw.js`)를 통해 **오프라인(지하 스윙 빠 등 인터넷이 없는 환경)에서도 앱이 그대로 열립니다.**
*   **맥북 (macOS) / Windows PC**:
    1. **Google Chrome** 또는 **Microsoft Edge**로 위 주소에 접속합니다.
    2. 주소창 우측의 **앱 설치(🖥️↓)** 아이콘을 누르면 독립된 데스크탑 앱 창으로 설치해 사용할 수 있습니다.

### 방법 2. 로컬 폴더에서 실행 (오프라인 로컬 서버)
소스 코드를 직접 내려받아 로컬에서 실행할 수도 있습니다 (Node.js 또는 Python 필요).

*   **Windows**: 폴더 내 `start.bat` 더블 클릭 (종료 시 `stop.bat` 실행)
*   **macOS / Linux**:
    ```bash
    chmod +x start.sh stop.sh  # 최초 1회 실행 권한 부여
    ./start.sh
    ```

> 💡 **권장 브라우저**: 메인 스피커와 헤드폰(CUE) **출력 장치 분리(`setSinkId`)** 및 **파일 핸들 영구 저장** 기능을 100% 활용하려면 모든 운영체제에서 **Google Chrome** 또는 **Microsoft Edge** 사용을 권장합니다.

## 🛠️ 기술 사양 (Technical Specs)

*   **Audio Engine**: Web Audio API Native Sample Rate Sync, Pure Direct Hard Bypass, Parallel Spectrum Tap, Butterworth Proportional-Q 5-Band EQ, Transparent Brickwall Limiter (`-0.5 dBFS`), Cosine-Exponential S-Curve Fade, Anti-Click Micro-Envelope (`7~8ms`)
*   **Analysis & Concurrency**: 격리된 `OfflineAudioContext` 디코딩 + 싱글톤 Web Worker 순차 BPM 분석 큐 + Gated RMS(`dBFS`) & Sample Peak 라우드니스 측정
*   **PWA & Offline**: Web App Manifest (`manifest.webmanifest`) + Network-First Service Worker (`sw.js`)
*   **Storage**: IndexedDB (`FileSystemFileHandle` & 다중 플레이리스트 보관함), LocalStorage (Settings, Custom EQ Presets, Theme)
